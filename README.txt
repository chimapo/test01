AZHI ART 個人插畫作品集

1. 直接雙擊 index.html，即可在瀏覽器查看網站。
2. 圖片放在 images 資料夾，程式碼分別是 index.html、style.css、script.js。
3. 若要免費公開上線：登入 Cloudflare Dashboard → Workers & Pages → Create → Pages → Direct Upload，將本資料夾上傳。
4. 網站會得到類似 azhi-art.pages.dev 的網址，實際名稱以 Cloudflare 可用名稱為準。
5. 網站作品標題是依畫面暫定的英文展示名稱，可以在 script.js 的 works 陣列中修改。
6. ABOUT 文案是示範稿，可自行修改成正式個人介紹。
